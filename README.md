# Elevvo Internship — NLP Track

This repository documents my work during the **Natural Language Processing (NLP) track** of the Elevvo internship.

As part of the internship, I'm assigned a series of NLP tasks covering different areas of the field — from text classification and sentiment analysis to named entity recognition and topic modeling. Each task is implemented as a complete, self-contained project: exploring the dataset, preprocessing the text, building and evaluating models, and documenting the results.

This repo will be updated progressively as new tasks are completed throughout the internship.
